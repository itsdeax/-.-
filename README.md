# ถ่ายสวย

แอปเว็บกล้องฟิลเตอร์ ถ่ายรูปให้สวยทันที ทำงานในเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ส่งรูปไปที่ไหน

## ฟีเจอร์

- ฟิลเตอร์สดบนภาพตัวอย่าง 10 แบบโทนสมัยใหม่ (คลีน, มิลค์, กลาสสกิน, บลัช, ซันนี่, พาสเทล, โครม, แฟลช, มินิมอล, ขาวดำ)
- แท็บ "กล้องฟิล์ม" สไตล์ Dazz: ดิจิแคม (CCD), คลาสสิก, ใช้แล้วทิ้ง, อินสแตนท์ (กรอบโพลารอยด์), ฟิล์ม 35, แฟลชปาร์ตี้, ขาวดำฟิล์ม พร้อมวันที่สีส้ม แสงฟุ้ง แสงรั่ว และกรอบมุมช่องมองภาพ (วันที่และกรอบติดไปกับรูปที่ถ่าย)
- ปรับระยะเลนส์ 1× / 2× / 3× / 5× (แตะปุ่มบนภาพ ใช้สองนิ้วถ่างซูม หรือเลื่อนล้อเมาส์บนคอม) เป็นซูมดิจิทัล ภาพที่ถ่ายใช้ความละเอียดจริงของส่วนที่ซูม
- แท็บ "พอร์ตเทรต" ปรับสีผิวกับพื้นหลังแยกกัน (ผิวฉ่ำ ครีมพีช ชานม เกาหลีใส ซอฟต์โกลว์ ซันคิส) และแท็บ "คอมแพค" โทนกล้องดิจิทัลคอมแพคสไตล์ G7X (G7X, Canon G12, EOS R, iP 7, X5, GR, Fuji CC, Velvia, Classic Neg, Astia, Leica M, Leica Q, Leica B&W) ที่ใช้ split toning แยกสีเงากับไฮไลต์
- ปุ่มแฟลช: กล้องหน้าใช้จอขาวสว่างวาบ กล้องหลังเปิดไฟแฟลชจริงตอนถ่าย (เบราว์เซอร์ที่รองรับ เช่น Chrome บน Android) ถ้าเปิดไฟจริงไม่ได้ เช่น iPhone Safari จะใช้แฟลชจำลองเร่งแสงและคอนทราสต์ตอนถ่ายแทน
- ปรับแต่งภาพแบบรูปใน iPhone (ปุ่มวงกลมครึ่งดำข้างปุ่มปรับ): แสง ความสว่างสดใส ไฮไลท์ เงา คอนทราสต์ ความสว่าง จุดดำ ความอิ่มสี ความสดสี อุณหภูมิ เฉดสี ความคมชัด ดีไฟน์ วิกเนตต์ เลือกค่าแล้วเลื่อนสไลเดอร์ (-100 ถึง +100) ค่าที่ปรับจะมีจุดบอก ดับเบิลคลิกสไลเดอร์หรือกดรีเซ็ตเพื่อคืนค่า ใช้กับรูปที่ถ่ายด้วย
- มิกซ์สี HSL (ชิปท้ายสุดในแผงปรับแต่ง): เลือก 1 ใน 8 สี (แดง ส้ม เหลือง เขียว ฟ้าเขียว น้ำเงิน ม่วง ชมพู) แล้วปรับโทนสี ความอิ่ม ความสว่างแยกกัน ค่าถูกจำไว้ในเครื่อง ดับเบิลคลิกสไลเดอร์เพื่อรีเซ็ตค่านั้น
- เลย์เอาต์เต็มจอ: ภาพกว้างเต็มความกว้างหน้าจอ แถบบนโปร่งลอยทับภาพ และปุ่ม "3:4" ข้างปุ่มสลับกล้องเปลี่ยนสัดส่วนภาพได้ 3:4, 9:16 (เต็มจอ ปุ่มควบคุมลอยทับ) และ 1:1 รูปที่ถ่ายใช้สัดส่วนตามที่เลือก
- ผิวเนียน และผิวใส (ปรับเฉพาะโทนผิว) พร้อมปรับความแรงของฟิลเตอร์
- ปุ่ม "แต่งหน้า" มี 4 แท็บ: ลุคสวย (กดครั้งเดียวได้ทั้งฟิลเตอร์ ผิว รูปหน้า เมคอัพ: ธรรมชาติ, หวานใส, เกาหลี, คมสวย, แดดสวย, ชมพูฟุ้ง), รูปหน้า (หน้าเรียว, กรามเล็ก, คาง, หน้าผาก, ตาโต, จมูกเล็ก, ปาก), ผิว (ผิวเนียน/ใส, ฟันขาว, ลดใต้ตาคล้ำ, ไฮไลท์, เฉดโหนกแก้ม) และเมคอัพ (ลิป, บลัช, อายแชโดว์ พร้อมปรับความเข้ม)
- ตั้งเวลาถ่าย 3 / 5 / 10 วินาที
- สลับกล้องหน้า/หลัง และไฟเติมหน้าจอสำหรับกล้องหน้า
- แต่งรูปจากแกลเลอรี (เลือกรูปที่มีอยู่มาใส่ฟิลเตอร์)
- แตะค้างที่ภาพเพื่อดูภาพต้นฉบับเทียบ
- บันทึกรูปเป็น JPEG หรือแชร์ (บนมือถือที่รองรับ)

ฟิลเตอร์และการปรับผิวคำนวณด้วย WebGL บนเครื่องของผู้ใช้ทั้งหมด

การปรับโครงหน้าและเมคอัพใช้ MediaPipe Face Landmarker (ไฟล์อยู่ใน `vendor/mediapipe`, Apache-2.0) ตรวจจุดบนใบหน้าในเครื่อง ไม่ส่งภาพออกไปไหน โมเดลโหลดเมื่อเปิดแผงแต่งหน้าครั้งแรก (ประมาณ 13 MB) และฟีเจอร์นี้ทำงานเมื่อเจอใบหน้าเดียวในภาพ

กล้องฟิล์มกำหนดไว้ใน `filters.js` ส่วน `THAISUAY_CAMERAS` ใช้พารามิเตอร์เดียวกับฟิลเตอร์ และเพิ่ม `model` (ชื่อบนช่องมองภาพ), `fx` (`bloom`, `leak`, `aber` ค่า 0-1), `stamp` (วันที่สีส้ม) และ `frame: "polaroid"`

## สร้างฟิลเตอร์เอง (สำหรับนักพัฒนา)

ฟิลเตอร์ทั้งหมดอยู่ในไฟล์ `filters.js` เพิ่มฟิลเตอร์โดยเติมอ็อบเจ็กต์ต่อท้ายอาร์เรย์:

```js
{
  id: "sunset",
  name: "ซันเซ็ต",
  chip: ["#ffb36b", "#c2417a"],
  p: { exposure: 0.2, temp: 0.7, tint: 0.6, vig: 0.5 },
},
```

พารามิเตอร์ใน `p` (ตัวที่ไม่ใส่จะใช้ค่าเริ่มต้น):

| ค่า | ช่วง | เริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `exposure` | -1 ถึง 1 | 0 | ความสว่าง |
| `contrast` | 0.6 ถึง 1.6 | 1 | คอนทราสต์ |
| `sat` | 0 ถึง 2 | 1 | ความอิ่มสี |
| `temp` | -1 ถึง 1 | 0 | ลบ = เย็น, บวก = อุ่น |
| `tint` | -1 ถึง 1 | 0 | ลบ = เขียว, บวก = ชมพู |
| `fade` | 0 ถึง 0.3 | 0 | ยกดำให้จาง (โทนแมท) |
| `vig` | 0 ถึง 1 | 0 | ขอบมืด |
| `grain` | 0 ถึง 0.2 | 0 | เกรนฟิล์ม |
| `mono` | 0 ถึง 1 | 0 | 1 = ขาวดำ |

### โหมด Lab

เปิดแอปด้วย `?dev=1` (เช่น `http://localhost:8000/?dev=1`) จะมีปุ่ม **Lab** มุมขวาบน
ปรับสไลเดอร์ดูผลสดบนภาพตัวอย่าง ตั้งชื่อและสีชิป แล้ว

- **สร้างจากรูปอ้างอิง** เลือกรูปที่ชอบโทนสี แอปวิเคราะห์สีในเครื่อง (ไม่อัปโหลดรูป) แล้วประมาณค่าแสง คอนทราสต์ ความอิ่มสี อุ่น/เย็น ชมพู/เขียว ดำจาง ขอบมืด และขาวดำ ให้ใกล้เคียงโทนของรูปนั้น แล้วปรับต่อด้วยสไลเดอร์ได้ ข้อควรรู้: เป็นการประมาณ และเนื้อหาในรูปมีผล (เช่น รูปผนังสีแดงอาจถูกอ่านว่าโทนอุ่น) ฟิลเตอร์ที่ได้เก็บแค่ตัวเลข ไม่มีรูปต้นฉบับติดไป ใช้โทนสีจากรูปของผู้อื่นเฉพาะที่ได้รับอนุญาต และไม่ควรเก็บรูปนั้นไว้ใน repo
- **บันทึกในเครื่อง** เก็บเป็นฟิลเตอร์ส่วนตัวในเบราว์เซอร์นี้ (localStorage) แสดงต่อท้ายแถบฟิลเตอร์
- **คัดลอกลิงก์ (ส่งไปมือถือ)** ได้ลิงก์ที่มีฟิลเตอร์ฝังอยู่ เปิดบนมือถือแล้วฟิลเตอร์จะถูกนำเข้าและเลือกให้เอง (ฟิลเตอร์ที่บันทึกในเครื่องอยู่เฉพาะในเบราว์เซอร์ของเครื่องนั้น ไม่ซิงก์ข้ามเครื่อง) ควรสร้างจากหน้าเว็บที่เผยแพร่แล้ว ไม่ใช่ `localhost` เพื่อให้ลิงก์เปิดบนมือถือได้
- **คัดลอกโค้ด** ได้โค้ดอ็อบเจ็กต์พร้อมวางลงใน `filters.js` เพื่อให้ทุกคนใช้ได้

ในโหมด `?dev=1` มีบรรทัดข้อมูลวินิจฉัยเล็กๆ ด้านบนภาพ (การ์ดจอ, ขนาดภาพ, ฟิลเตอร์ที่เลือก, ความแรง, fps) ใช้ตรวจเมื่อฟิลเตอร์ไม่ทำงานบนเครื่องใดเครื่องหนึ่ง

## ลองรัน

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

เปิด http://localhost:8000 (บน Windows ใช้ `py -m http.server 8000`)

## หมายเหตุ

- ต้องอนุญาตสิทธิ์กล้อง และต้องเปิดผ่าน HTTPS หรือ localhost เท่านั้น
- ต้องใช้เบราว์เซอร์ที่รองรับ WebGL
- ตัวปรับผิวเนียนเป็นการเบลอแบบรักษาขอบเฉพาะโทนผิว ไม่ได้ตรวจจับใบหน้า
