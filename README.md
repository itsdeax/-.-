# ถ่ายขาย

แอปเว็บแนวกล้องถ่ายรูป สำหรับลงขายสินค้า: ถ่ายรูป → ใส่ชื่อ/ราคา → เก็บในรายการของฉัน

## ขั้นแรกที่ทำแล้ว

1. เปิดกล้องเต็มจอ (หรือเลือกรูปจากแกลเลอรี)
2. กดชัตเตอร์ถ่ายรูป
3. กรอกชื่อ ราคา รายละเอียด แล้วกดลงขาย
4. ดู/ลบรายการในหน้า “ของฉัน” (เก็บใน `localStorage` บนเครื่องคุณ)

## ลองรัน

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

เปิด http://127.0.0.1:8000 บนมือถือหรือเบราว์เซอร์ที่อนุญาตกล้อง

## หมายเหตุ

- ต้องอนุญาตสิทธิ์กล้องในเบราว์เซอร์
- HTTPS หรือ localhost จึงใช้กล้องได้ในเบราว์เซอร์ส่วนใหญ่
- ยังไม่มีบัญชีผู้ใช้ / ฐานข้อมูลออนไลน์ / ระบบชำระเงิน (ทำในขั้นถัดไปได้)
