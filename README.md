# ถ่ายสวย

แอปเว็บกล้องฟิลเตอร์ ถ่ายรูปให้สวยทันที ทำงานในเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ส่งรูปไปที่ไหน

## ฟีเจอร์

- ฟิลเตอร์สดบนภาพตัวอย่าง 9 แบบ (ธรรมชาติ, ครีมนุ่ม, พีช, โรส, ใสปิ๊ง, ฟิล์ม, โกลเด้น, ฟ้าเย็น, ขาวดำ)
- ผิวเนียน และผิวใส (ปรับเฉพาะโทนผิว) พร้อมปรับความแรงของฟิลเตอร์
- ตั้งเวลาถ่าย 3 / 5 / 10 วินาที
- สลับกล้องหน้า/หลัง และไฟเติมหน้าจอสำหรับกล้องหน้า
- แต่งรูปจากแกลเลอรี (เลือกรูปที่มีอยู่มาใส่ฟิลเตอร์)
- แตะค้างที่ภาพเพื่อดูภาพต้นฉบับเทียบ
- บันทึกรูปเป็น JPEG หรือแชร์ (บนมือถือที่รองรับ)

ฟิลเตอร์และการปรับผิวคำนวณด้วย WebGL บนเครื่องของผู้ใช้ทั้งหมด

## ลองรัน

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

เปิด http://localhost:8000 (บน Windows ใช้ `py -m http.server 8000`)

## หมายเหตุ

- ต้องอนุญาตสิทธิ์กล้อง และต้องเปิดผ่าน HTTPS หรือ localhost เท่านั้น
- ต้องใช้เบราว์เซอร์ที่รองรับ WebGL
- ตัวปรับผิวเนียนเป็นการเบลอแบบรักษาขอบเฉพาะโทนผิว ไม่ได้ตรวจจับใบหน้า
